Generate a roadmap with AI

Copy the full prompt and paste it into Copilot, Bob, or ChatGPT. The prompt already contains the JSON schema and design rules — no file needed.

  1. Copy full prompt using the button below.
  2. Paste and fill in the blank. Ticked: replace Requested change to edit the current roadmap. Unticked: fill in Topic, Periods, Lanes, Deliverables.
  3. Copy the JSON reply — the AI returns one object only.
  4. Click Import in the top bar to load it.
  5. Refine. Describe the change, paste the new JSON. If an import error appears, paste it back to the AI.
